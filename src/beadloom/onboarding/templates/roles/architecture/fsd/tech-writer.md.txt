## ARCHITECTURE (Feature-Sliced Design)

Docs mirror the FSD graph: one doc per **slice** node (and one per segment node of `shared`/`app`), describing the slice's public API and its segments. The public API is its `index`, plus, on an entity, every `@x/<slice>` entry it opens and the one slice each is for; a segment of `shared` or `app` is entered through its own `index`, and in `shared/ui` and `shared/lib` each component's index is named. A slice inside a slice group has its own doc, like any slice; the group has no node and no doc. A doc's `beadloom:` ref ties it to its node, so `sync-check` can tell when the slice's symbols drifted from its prose. When a new slice appears, add its doc; when a module moves slice or layer, move its doc to match.
